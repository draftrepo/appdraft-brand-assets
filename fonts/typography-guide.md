# APPDRAFT Typography Guide

## Primary Font: Inter

Inter is a clean, modern sans-serif font designed for screen readability.

### Font Weights

| Weight | Value | Usage |
|--------|-------|-------|
| Light | 300 | Subtle text, large headings |
| Regular | 400 | Body text, paragraphs |
| Medium | 500 | Buttons, labels, emphasis |
| Semibold | 600 | Headings, subheadings |
| Bold | 700 | Strong emphasis, key information |

### Font Sizes

| Name | Size | Usage |
|------|------|-------|
| xs | 12px | Captions, footnotes |
| sm | 14px | Secondary text, metadata |
| base | 16px | Body text |
| lg | 18px | Lead paragraphs |
| xl | 20px | Small headings |
| 2xl | 24px | Section headings |
| 3xl | 30px | Page headings |
| 4xl | 36px | Hero headings |

### Loading Inter

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&display=swap" rel="stylesheet">
```

### CSS Usage

```css
body {
  font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
}
```

## Logo Font: Eurostile BQ

The APPDRAFT logo uses Eurostile BQ Extended, a geometric sans-serif with a technical, modern feel.

- **Style:** Extended/Wide
- **Weight:** Medium to Bold
- **Case:** Uppercase
- **Letter Spacing:** 0.05em - 0.1em
- **Color:** #0b3d52 (dark teal) on light backgrounds, white on dark backgrounds
